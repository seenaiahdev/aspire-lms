# Aspire LMS

A React + TypeScript LMS dashboard built with Vite and Tailwind CSS.

## Deployment
This project is configured for Vercel deployment using `vercel.json`.

### Build command
```bash
npm run build
```

### Output directory
Vite outputs the static site to `dist/`.

### Vercel setup
1. Connect the repository to Vercel.
2. Set the framework preset to `Vite`.
3. Use the default build command: `npm run build`.
4. Use the default output directory: `dist`.

## Local development
```bash
npm install
npm run dev
```
